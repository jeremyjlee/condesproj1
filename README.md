# **"Butterfly" Project Overview**
The "Butterfly" project explores the relationship between human input and AI-generated outputs using **RunwayML**'s image-to-text and edge detection features. The process involves generating abstract yet coherent images and tracing their edges to examine AI's ability to interpret and replicate human-defined structures. The project also incorporates a **dynamic website** built with **HTML, CSS, and JavaScript**, where visitors can experience an interactive and evolving display of nouns, images, and their traced outlines.

---

## **Process Description**
### 1. **Noun-Based Image Generation**
- Using **RunwayML**, a list of nouns was input to generate abstract images.
- These images are coherent yet maintain an abstract quality, showcasing AI's creative output based on simple textual prompts.

### 2. **Edge Detection with AI**
- The images were further processed using an AI edge detection program to analyze whether the AI could accurately trace the contours of its own generated images.
- This step highlights the AI's capacity to recognize and replicate key features of its creations.

### 3. **Website Functionality**
- Built with **HTML, CSS, and JavaScript**, the website allows users to interact with the project dynamically.
- When refreshed (**Ctrl+R**), the displayed nouns, generated images, and their traced versions are updated, offering a continuously evolving experience.
- The interaction starts with the display of a noun, followed by the generated image and its traced version, creating a seamless progression.

### 4. **Design Inspiration**
- The website’s introductory design draws inspiration from **Netflix's iconic intro sequence**.  
  - Similar to Netflix's zoom-in effect following its signature sound and logo, the site begins with a long, striking image that transitions smoothly into the interactive content.  
  - This design choice enhances the user experience by building anticipation and engagement.

---

## **Key Features**
- **Dynamic Interaction**: Each refresh showcases a new pairing of nouns, images, and traced outlines.  
- **Artistic Exploration**: Abstract imagery combined with edge detection offers insights into AI's interpretive abilities.  
- **Immersive Design**: A visually engaging intro, inspired by Netflix, adds a cinematic feel to the user experience.
